# DEUS · Save to Cast

## Install

1. Extract this archive into a GitHub repository. Put spindle.json and dist directly at its root.
2. Replace YOUR-ACCOUNT/deus-save-to-cast in spindle.json with that repository's owner and name.
3. In Lumiverse's Extensions panel, install from that repository URL. Enable the extension and grant Characters, Chats, and World Books access.

## Use

Open a DEUS New Faces card and choose Save to Cast. Review the destination, names, and profile, then save. Each RPG character card gets a separate cast book on first save. Chats using the same RPG card share that book. Names and aliases activate entries. Existing attached books are preserved.

Open a saved NPC's action again to review an update. The previous profile is shown above the editable version. Remove superseded facts before saving. A changed entry must be reopened if another save happened while you were editing. Profiles can also be edited in Lumiverse's World Books panel.
